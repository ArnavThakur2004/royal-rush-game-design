# Royal Rush — Mobile Game Design Case Study

## Overview

Royal Rush is a fictional free-to-play social casino game design case study exploring how a simple slot gameplay loop can be expanded through player choice, progression, and virtual economy design.

The project focuses on the design process rather than production-level implementation.

## Core Design Question

**How can a simple slot gameplay loop introduce meaningful player choice while remaining accessible for short mobile sessions?**

## Core Gameplay Loop

**SPIN → REWARD → BUILD STREAK → UNLOCK BONUS → BANK OR RISK → PROGRESS → SPIN AGAIN**

## Key Feature

### Bank or Risk

When players reach a designated streak milestone, they can choose between:

* **Bank:** Receive a guaranteed virtual reward.
* **Risk:** Attempt a bonus interaction for the possibility of a larger virtual reward.

The mechanic introduces a lightweight decision-making layer into the core gameplay loop.
